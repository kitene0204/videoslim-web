# 🎬 VideoSlim Web — 동영상 화질 유지 압축 & 확장자 변환기

외부 서버로 동영상을 올리지 않고 **100% 웹 브라우저 내부(FFmpeg.wasm)**에서 안전하게 동영상을 압축하고 확장자를 변환하는 웹 어플리케이션입니다.

## ✨ 주요 기능
- **💬 카카오톡 전송 기준 (300MB 이하)**: 카카오톡 동영상 전송 한도에 맞춰 화질을 최대한 유지하며 압축
- **📦 500MB 이하 맞춤 압축**: 500MB 이하 플랫폼·제출 기준 자동 맞춤
- **✨ 화질 유지 자동 압축 (CRF)**: 눈으로 보기에 원본과 거의 동일한 화질을 유지하면서 불필요한 용량 절감
- **🎛️ 목표 용량 직접 입력 (MB)**: 원하는 최대 용량(MB)을 직접 입력해 압축
- **🔄 동영상 확장자 변환**: `MP4`, `MOV`, `MKV`, `AVI`, `WEBM` 지원
- **📂 드래그 앤 드롭 & 결과 미리보기**: 파일을 끌어다 놓으면 바로 분석되며, 완료 후 브라우저에서 바로 재생 및 다운로드 가능
- **🔒 100% 로컬 처리 보안**: 영상 파일이 외부 서버로 전혀 전송되지 않습니다.

## 🛠️ 기술 스택
- React 19 + TypeScript + Vite
- Tailwind CSS v4
- FFmpeg.wasm (`@ffmpeg/ffmpeg`, `@ffmpeg/util`)
- Vercel 배포
